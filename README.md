# Comb Sort Visualizer

Comb Sort Visualizer is a C# desktop application for visualizing how the Comb Sort algorithm works.

## Overview

The application demonstrates the sorting process through a desktop interface and helps explain the behavior of the Comb Sort algorithm step by step.

## Features

- Visual sorting animation
- Step-by-step algorithm representation
- Desktop user interface
- Educational visualization of Comb Sort
- Simple C# project structure

## Tech Stack

- C#
- WPF
- XAML
- .NET Framework
- Visual Studio
