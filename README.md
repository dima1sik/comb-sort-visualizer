# Comb Sort Visualizer

Comb Sort Visualizer is a C# desktop application for visualizing the Comb Sort algorithm.

## Overview

The application demonstrates how Comb Sort works by animating the sorting process in a desktop interface.  
It was created as an educational algorithm visualization project.

## Features

- Visual sorting animation
- Step-by-step algorithm representation
- Desktop interface
- Educational visualization of Comb Sort

## Tech Stack

- C#
- WPF
- XAML
- .NET Framework
- Visual Studio

## How to Run

1. Open CombSortVisualizer.sln in Visual Studio.
2. Build the solution.
3. Run the project.
